# Requirements — Milestone v2.0: Click-to-Move

## v2.0 Requirements

### Selection
- [ ] **SEL-01**: User can tap a player on a court to select them (visual highlight)
- [ ] **SEL-02**: User can tap an inactive player to select them (visual highlight)
- [ ] **SEL-03**: User can tap the selected player again to deselect them
- [ ] **SEL-04**: User can tap a non-target area to deselect the current selection

### Movement
- [ ] **MOV-01**: User can tap a court background to move the selected player into that court (uses addPlayerToCourt logic)
- [ ] **MOV-02**: User can tap another player to swap them with the selected player (uses swapPlayer logic)

### Coexistence
- [ ] **COE-01**: Drag-and-drop continues to work alongside tap-to-move with no regressions

## Future Requirements

_None deferred for this milestone._

## Out of Scope

- **Multi-select** — selecting multiple players at once; single-selection is sufficient for the swap/move workflow
- **Undo move** — no undo button for tap-to-move actions; matches existing drag-and-drop behavior
- **Gesture customization** — no settings to configure tap vs drag preference
